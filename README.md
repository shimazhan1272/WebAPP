# ボートレースAI予想 Web アプリケーション

全国24箇所のボートレース場に対応し、出走表・直前展示情報（展示タイム・スタート展示・気象水面データ）を取得して統計モデル（Plackett-Luce モデル）により1着確率・スリット隊形・推奨買い目（フォーメーション形式）を算出する PWA 対応 Web アプリケーションです。

---

## 1. 特徴・機能一覧

1. **全国24場・全12レース完全対応**
   - 桐生、戸田、江戸川、平和島、多摩川、浜名湖、蒲郡、常滑、津、三国、びわこ、住之江、尼崎、鳴門、丸亀、児島、宮島、徳山、下関、若松、芦屋、福岡、唐津、大村（全24場網羅）
2. **PWA（Progressive Web App）対応**
   - スマホ（iOS Safari / Android Chrome）や PC デスクトップのホーム画面にインストール可能
   - オフライン時の状態表示
3. **展示情報・スリット隊形可視化（SVG）**
   - 各艇の展示タイム、進入コース順、スタート展示の ST（スタートタイミング）をスリットライン対比のグラフィカルな隊形図として表示
4. **気象情報と風補正ルール自動適用**
   - 風速（m/s）、風向（追い風/向かい風/横風）、波高（cm）を考慮した統計補正
5. **AI推奨買い目のフォーメーション集約（1列表示）**
   - 3連単、2連単、3連複の買い目をカンマなしのフォーメーション形式（例: `1-2-3456`, `12-12-3456`）でスマートに集約
   - 個別の買い目と確率の内訳もワンタップで展開確認可能
6. **予想モデル係数調整（スライダー）**
   - 当地2連率、モーター2連率、展示タイムの重視度をリアルタイムに微調整
7. **手動修正機能**
   - 展示タイム、風速、風向、波高、進入コースを自由に編集して即時再計算
8. **入力の自動永続化**
   - 前回利用した開催日、レース場、レース番号、買い目点数、スライダー係数を `localStorage` に自動保存

## 2. セットアップ ＆ 起動手順

### 必要環境
- Node.js 18+
- npm / yarn / pnpm / bun

### インストールと開発起動
```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動 (ポート 3000)
npm run dev
```

ブラウザで `http://localhost:3000` を開きます。

### プロダクションビルド
```bash
npm run build
```
ビルド成果物は `dist/` ディレクトリに生成されます。

### GitHub Pages 等での公開手順
1. 本リポジトリを GitHub に push します。
2. GitHub リポジトリの **Settings** > **Pages** を開きます。
3. Source を **GitHub Actions** に設定します。
4. 静的サイトホスティング（GitHub Pages、Vercel、Cloudflare Pages、Netlify 等）にデプロイすることで、世界中どこからでもブラウザから直接利用できます。

## 3. 展示情報取得の仕組みと boatrace.jp プロキシ設定

本アプリは以下の優先順位で出走表および直前展示情報を取得します。

### 取得順序
1. **Boatrace Open API（一次ソース）**
   - `https://boatraceopenapi.github.io/programs/v2/{YYYY}/{YYYYMMDD}.json`
   - `https://boatraceopenapi.github.io/previews/v2/{YYYY}/{YYYYMMDD}.json`
   - CORS対応・認証不要でブラウザから直接高速に取得可能です。
2. **boatrace.jp 公式サイト HTML 解析（二次ソース）**
   - 直前展示情報（展示タイム・進入・気象）が最新で反映されている公式ページを自動解析します。
   - `boatrace.jp` はブラウザからのクロスオリジン（CORS）通信を制限しているため、以下のプロキシを経由して取得します。
     - **ローカル開発環境**: `vite.config.ts` に設定済みの開発プロキシ `/api/boatrace-jp/*` を自動利用。
     - **Web公開環境 (GitHub Pages等)**: 公開 CORS プロキシ（AllOrigins 等）へ自動フォールバック。
3. **展示前・未公開時のフォールバック**
   - 直前情報がまだ公開されていない場合でもアプリはクラッシュせず、「直前情報なし」として展示タイム補正と風補正を 0 として計算を続行します。ユーザーは手動修正カードから値を自由に入力して予想を生成できます。

#### 独自のプロキシサーバー（Cloudflare Workers など）を使用する場合
Cloudflare Workers で数行の CORS プロキシを作成し、`boatraceApi.ts` の `fetchOfficialHtml` にエンドポイントを指定することで、より高速かつ安定した通信が可能です。

## 4. 予想モデル係数調整の使い方

「予想モデル係数調整」アコーディオンを開くと、3つのスライダーが表示されます。

| 項目 | 基準係数 | 説明 |
| :--- | :--- | :--- |
| **当地2連率 係数 (cL2)** | 0.010 | 選手の当該レース場水面での適性・過去成績の重視度 |
| **モーター2連率 係数 (cM2)** | 0.012 | 抽選モーターの2連対率重視度 |
| **モーター3連対率 係数 (cM3)** | 0.008 | 抽選モーターの3連対率重視度 |
| **展示タイム補正 係数 (cEx)** | 6.0 | 直前展示航走タイムの差の重視度 |

### 実効係数の計算式
$$\text{実効係数} = \text{基準値} \times \left(1 + \frac{\text{スライダー値}}{3}\right)$$

- **スライダー値 0.0**: 基準値通りの標準モデル（100%）
- **スライダー値 +3.0**: 係数が2倍（200%）になり、その項目の影響力が強まります。
- **スライダー値 -3.0**: 係数が0（無効化）になり、その項目を予想計算から完全に除外します。

各スライダーの横に「スライダー値 → 実効係数」が表示され、「0に戻す」ボタンで瞬時に初期値に戻せます。スライダーを操作するとデータ再取得なしで**即座に確率と買い目が再計算**されます。

## 5. 展示タイム・気象データ・進入コースの手動修正の使い方

「展示タイム・気象データ・進入コースの手動修正」アコーディオンでは、以下の項目を自由に編集できます。

1. **各艇の展示タイム**: 各艇の展示タイムを入力（例: `666` と入力すると自動で `6.66` に変換されます。もちろん `6.66` 直接入力も可能）。
2. **各艇の進入コース（1〜6）**:
   - スタート展示で前付けがあった場合や、本番レースで進入が枠なりと異なると予想される場合に変更できます。
   - 進入が枠なり（1-2-3-4-5-6）と異なる場合、結果ヘッダーに「前付けあり（進入が枠なりと異なる）」と隊形（例: `4-1-2-3-5-6`）が表示されます。
   - 進入コースに重複や欠落がある場合は警告が表示され、枠なりとして安全に計算されます。
3. **風速（m/s）**: 0〜20m/s の風速を指定（0を消して空欄からスムーズに入力可能）。
4. **風向**:
   - 「追い風」（イン有利〜2コース差し有利）
   - 「向かい風」（3コース・4コースのまくり有利）
   - 「横風」
   - 「無風」
5. **波高（cm）**: 水面の波高を指定（0を消して空欄からスムーズに入力可能）。

※ 手動修正欄の値を変更すると、通信を発生させずに即座に予想が再計算されます。「取得初期値に戻す」ボタンでいつでも元の取得データに戻せます。

## 6. 推奨買い目と確率の見方

### 買い目点数の指定
- 券種: **3連単** / **2連単** / **3連複**
- 点数は **0〜30点** をセレクトプルダウンから選択（0点に設定した券種は非表示）。変更時は即時再計算されます。

### フォーメーション表記（カンマなし）
複数の買い目をボートレース標準のフォーメーション形式でまとめて表示します。
- `1-2-3456`: 1着が1号艇、2着が2号艇、3着が3・4・5・6号艇（計4点）
- `12-12-3456`: 1・2着が1号艇と2号艇の裏表、3着が3・4・5・6号艇（計8点）
- `1-234`: 2連単で1着が1号艇、2着が2・3・4号艇（計3点）
- `1=2=345`: 3連複で1・2号艇を軸に、相手が3・4・5号艇（計3点）

### 確率（%）の定義
- **各買い目の確率**: その着順で入線する統計モデル（Plackett-Luce）の推定確率。
- **フォーメーション行の合算確率**: そのフォーメーションに含まれる個別の買い目確率の合計値。
- 各フォーメーション行の右側にある矢印アイコンをタップすると、含まれる個別買い目とその確率の内訳を確認できます。

## 7. 予想ロジックの概要（CONFIG）

統計モデルは `src/utils/constants.ts` の `CONFIG` および `src/utils/predictor.ts` に純関数として実装されています。

### スコア計算式
各艇 $i$（進入コース $c_i$、艇番 $b_i$）のスコア:
$$\begin{aligned}
\text{score}_i =\ & c_{\text{Prior}} \times \ln(\text{PRIOR\_COURSE}[c_i]) \\
& + c_{\text{Win}} \times (\text{全国勝率}_i - 5.5) \\
& + c_{\text{N2}} \times (\text{全国2連率}_i - 35) \\
& + c_{\text{L2}}' \times (\text{当地2連率}_i - 35) \\
& + c_{\text{M2}}' \times (\text{モーター2連率}_i - 35) \\
& - c_{\text{St}} \times \text{COURSE\_MULT.st}[c_i] \times (\text{平均ST}_i - 0.16) \\
& + c_{\text{Grade}} \times \text{GRADE\_ADJ}[\text{級別}_i] \\
& - c_{\text{Ex}}' \times \text{COURSE\_MULT.ex}[c_i] \times (\text{展示タイム}_i - \overline{\text{展示タイム}}) \\
& + \text{windAdj}[c_i] \\
& + \text{FRONT\_ENTRY\_PENALTY} \times \max(0, b_i - c_i)
\end{aligned}$$

### 風補正ルール (`windAdj`)
- **強風（風速 $\ge 5$m/s）**: 1コースに $-0.30 \times m$（追い風時は 0.5倍の $-0.15 \times m$）
- **追い風（風速 $\ge 5$m/s）**: 2コースに $-0.20 \times m$
- **中風以上（風速 $\ge 4$m/s）**: 3コースに $+0.15 \times m$、4コースに $+0.20 \times m$
- 超過倍率: $m = \min(1.5, 1 + 0.15 \times (\text{風速} - \text{閾値}))$

### 順列確率（Plackett-Luce モデル）
スコアから1着確率 $p_i = \frac{\exp(\text{score}_i)}{\sum \exp(\text{score})}$ を算出し、着順確率を算出します:
$$P(a \to b \to c) = p_a \times \frac{p_b}{1 - p_a} \times \frac{p_c}{1 - p_a - p_b}$$
